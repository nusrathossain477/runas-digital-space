# Runa's Digital Haven

Build a complete, polished, responsive personal portfolio website for Nusrat Hossain Runa, a Computer Science & Engineering student at Green University of Bangladesh.

The website should feel like a premium academic + professional personal portfolio, not a generic software developer template. It should present my identity, skills, expertise, CV, projects, study materials, activities, achievements, and contact information in a clean, modern, elegant way.

Create a modern, minimal, sophisticated dark-themed interface.

Subtle purple and blue gradient accents

Thin, elegant borders

Rounded cards

Large modern typography

Smooth scrolling

Professional but slightly futuristic
